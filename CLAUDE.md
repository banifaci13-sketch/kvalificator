# Правила проекта «Ассистент» Soroka Marketing

## Главное: это отдельный проект — ни с чем не смешивать

Этот репозиторий — **только** кабинет агентства Soroka Marketing.
**«Кабинет Корпорации» («КОРПОРАЦИЯ») — другой, отдельный проект.** Они никогда не пересекаются:

- **Сервер, папка и домен Сороки** — `194.67.101.183`, `/opt/kvalificator`, `soroka-assistant.ru` — только для Сороки.
  Никогда не разворачивать туда другой проект, не менять там nginx/Caddy, `.env`, контейнеры или базу ради
  другого проекта.
- **Код Сороки** — в этот репозиторий не добавлять ничего для другого проекта: ни настроек, ни инструкций,
  ни веток, ни коммитов. Если нужна копия кода для другого проекта — только отдельным архивом, без
  изменений здесь.
- **Бренд, логотип, данные** — не переносить между проектами: ни логотипы, ни сотрудников, ни клиентов,
  ни базу, ни `.env`.
- Если просьба касается другого проекта или непонятно, о каком проекте речь, — **сначала уточнить**,
  ничего не трогать.

## Остальные правила

- Не разворачивать самому. Обновление на сервере запускает владелец:
  `ssh root@194.67.101.183` → `cd /opt/kvalificator` → `bash deploy/update.sh` (команды — по одной, отдельными блоками).
- Pull request — только по просьбе.
- Логотип не генерировать и не перерисовывать — только оригинальные файлы бренда.
- ИИ не придумывает цифры; сумму, цены и показатели считает код.
- Персональные данные — на сервере в РФ, в ИИ — только обезличенные.
- Ключи и пароли — только в `.env` на сервере (репозиторий публичный).
- Не отключать nginx: на сервере есть другие сайты.
- Внешние подключения и действия во внешних системах — только после согласования с владельцем.
- Ответы владельцу — по-русски.
