# Оригинальные логотипы

Сюда кладутся только оригинальные утверждённые файлы (SVG или PNG) — из шапки сайта или от дизайнера.
Не перерисовывать знак и не брать картинки из сторонних каталогов.

После добавления:
1. `npm run brand:sync` покажет sha256 файлов.
2. В brand/brand.config.json → logo укажите onLight / onDark, их sha256 и status: "verified".
