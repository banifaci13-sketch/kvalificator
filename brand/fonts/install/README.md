# Шрифты для компьютеров сотрудников

Презентации в PPTX используют шрифты Manrope (заголовки) и Inter (текст). Чтобы PowerPoint
показывал их как задумано, установите оба файла из этой папки (двойной клик → «Установить»).
Без них PowerPoint подставит похожий шрифт, и текст может лечь иначе.
