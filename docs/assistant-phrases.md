# Фразы ассистента

Всё, что ниже, ассистент выполняет сам, по правилам, без ИИ: мгновенно и даже когда YandexGPT
не подключён. Падежи, «ё/е», регистр и знаки препинания не важны; сроки понимает в живой форме
(«завтра в 11», «в пятницу», «20.10 к 18:00», «через неделю», «на следующей неделе»).

Если фраза сказана по-другому, ассистент отдаёт её YandexGPT. Модель не выполняет действий сама,
а только переписывает просьбу в одну или несколько фраз из этого списка («КОМАНДА: …»), и их
выполняют те же правила, с теми же проверками и правами. Свободные вопросы (составить текст,
разложить задачу, как у нас принято по регламентам) уходят в модель как обычный разговор.

Правила лежат в `src/assistant/phrases.js` и `src/assistant/commands.js`, действия — в
`src/assistant/actions.js`, проверка всех фраз — `test/phrases.test.js`. Добавляя правило,
допишите фразу и сюда, и в тест.

## Задачи

| Что сказать | Что произойдёт |
|---|---|
| поставь задачу подготовить КП для Таллера на пятницу | задача в проекте «Таллер», срок — пятница, исполнитель — вы |
| поручи Даниилу сделать медиаплан до 20.10 срочно | исполнитель — Даниил, важность высокая |
| задача: обновить нормативы | задача в «Общих задачах» |
| напомни позвонить в Медлайн завтра в 11 | задача-напоминание со временем |
| закрой задачу по лендингу · я сделал отчёт · баннеры готовы | отметить выполненной |
| верни в работу задачу отчёт | снять отметку «выполнена» |
| перенеси отчёт на понедельник в 12 · срок по баннерам — завтра · поменяй срок задачи отчёт на 25.10 | новый срок |
| перенеси её на пятницу | задача, о которой только что шла речь |
| передай задачу баннеры Олегу · назначь задачу отчёт на Даниила · пусть Олег сделает баннеры · перекинь отчёт на меня | сменить исполнителя (ему придёт уведомление) |
| сделай задачу отчёт критичной · отметь баннеры как срочную · важность задачи отчёт низкая | важность |
| комментарий к задаче баннеры: макеты в папке · напиши в задачу отчёт: @Олег проверь цифры | комментарий; @Имя — упоминание с уведомлением |
| удали задачу тест | спросит подтверждение, удалит только автор или администратор |
| открой задачу баннеры · где задача про отчёт? | откроет карточку задачи |

Если подходят несколько задач, ассистент не угадывает, а показывает варианты кнопками.

## Клиенты и проекты

| Что сказать | Что произойдёт |
|---|---|
| добавь клиента Юнистрим · создай клиента «Юнистрим» · добавь проект Леокид | новый клиент (и проект в «Задачах»), менеджер — вы |
| заведи нового клиента Юнистрим, сайт unistream.ru, контакт Иван, +7 999 123-45-67 | с сайтом, контактом и телефоном |
| заведи клиента по заявке 123 | клиент из заявки квалификатора |
| список клиентов · мои клиенты | список с открытыми и просроченными задачами |
| что по Таллеру · что с Ромашкой? · сводка по клиенту Медлайн | задачи, ближайшая встреча, медиапланы |
| открой клиента Таллер | карточка клиента |
| в архив клиента Ромашка | архив (история сохраняется) |
| создай доску Трафик в проекте Таллер · добавь доску «Контент» для Ромашки | новая доска в проекте |

Клиента достаточно назвать одним характерным словом («Медлайн» вместо «Клиника Медлайн»),
если такое слово есть только у одного клиента.

## Медиапланы и документы

| Что сказать | Что произойдёт |
|---|---|
| создай медиаплан для Таллера на квартал · сделай МП для Юнистрима на 6 месяцев | новый медиаплан, откроется сразу |

| открой медиаплан Таллер · открой последний медиаплан | открыть |
| создай КП для Юнистрима · подготовь коммерческое предложение для Таллера | документ по шаблону КП с подставленным клиентом |
