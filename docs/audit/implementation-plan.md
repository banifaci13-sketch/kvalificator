# План реализации

**Сложность:** S — до дня, M — 2–4 дня, L — неделя, XL — больше недели.

**Каждый этап:**
- короткая записка в начале (что меняем, миграции, откат);
- тесты, `npm test` зелёный, `npm run bench` — без деградации;
- отчёт и команда обновления.

**Опасные и внешние действия** — только после согласования:
- подключение кабинетов;
- отправка копий за пределы сервера;
- любые записи во внешние системы.

## Этапы 5–7 (P1)

Детализируются после этапа 4: к тому времени станет ясно, какие данные реально приходят.

- **Сквозной процесс** — шаблоны регламентов «Новый клиент: контекст», «Ежемесячное ведение» и др. на
  существующем механизме «регламент → доска», плюс стадия клиента. M–L.
- **Сигналы** — CPL вырос, перерасход, нет конверсий при расходе, синхронизация упала, горячий лид не взят за SLA.
  Защита от шума: порог объёма, пауза, «решено/ложное». L.
  - Сигнал «горячий лид не взят» не зависит от Директа, его можно сделать раньше. S.
- **Главная по ролям** — «Руководитель», «Аккаунт», «Специалист» как наборы карточек существующей Главной. M.
- **Учёт времени и маржинальность** — только после открытого решения 6. L.

## Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| Яндекс не одобрит доступ к API Директа или будет рассматривать долго | средняя | подать заявку сразу; до ответа вести ветку ассистента |
| Расхождение цифр Директа и Метрики (атрибуция, часовой пояс, НДС) | высокая | показывать источник у каждой цифры, не складывать конверсии разных систем, сверять с выгрузкой из кабинета |
| YandexGPT плохо держит JSON-формат | средняя | проверка схемы, запасной путь через каталог фраз |
| Рост диска из-за бэкапов файлов | низкая | зеркало без дублей (файлы по sha256), размер виден на странице «Состояние» |
| Регрессия старых функций | низкая | 245 автотестов + новые на каждый этап, `bench` для скорости |

## Тест-план (дополнения к текущим 245)

- **Бэкап и восстановление:** копия содержит базу и все файлы; проверка находит пропавший файл и битую базу.
- **Состояние системы:** менеджеру 403; без входа 401; в ответе нет секретов и ПДн.
- **Ассистент:**
  - команда от ИИ на изменение не выполняется без подтверждения;
  - чтение выполняется сразу;
  - инъекция в описании задачи не приводит к действию.
- **Метрики:** нулевые знаменатели, пустые периоды, валюта, повторная синхронизация без дублей, 429 и 5xx
  (на записанных ответах API).
- **Отчёт:** воспроизводится из снимка; пустые значения блокируют выгрузку.
