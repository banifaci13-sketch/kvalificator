# Резервные копии и восстановление

## Что копируется

Каждую ночь в 03:17 (cron из `deploy/install.sh`) и перед каждым обновлением (`deploy/update.sh`) запускается
`npm run backup`. В папке `data/backups/` появляется:

- `kvalificator-ГГГГ-ММ-ДД-ЧЧ-ММ.db` — копия базы. Делается без остановки сервера, хранятся 14 последних.
- `kvalificator-….json` — манифест: контрольная сумма копии, версия схемы, результат проверки целостности,
  сколько файлов.
- `data/files`, `data/media`, `data/documents` — зеркало вложений, медиатеки и выгрузок. Копируются только
  новые файлы. Удалённое в кабинете в зеркале остаётся: на него ссылаются старые копии базы.
- `status.json` — итог последнего бэкапа и проверки. Его показывает «Сотрудники» → «Состояние».

Сразу после копии идёт **проверка восстановления**: копия открывается во временной папке текущей версией
программы, проверяются целостность и контрольная сумма, а также то, что все файлы, на которые ссылается база,
лежат в зеркале. Её можно запустить и отдельно:

```bash
cd /opt/kvalificator
docker compose exec -T app npm run restore-check
```

**Не копируется:**

- файл `.env` с ключами — храните его отдельно, например в менеджере паролей;
- сертификаты HTTPS — они выпускаются заново.

Копии лежат **на том же сервере**. Они защищают от ошибки или порчи базы, но не от потери сервера. Копия в другом
месте — следующий шаг, после согласования, где её хранить.

## Как восстановить

1. Остановить приложение (другие сайты на сервере не затрагиваются):
   ```bash
   cd /opt/kvalificator && docker compose stop app
   ```
2. Отложить текущие данные — на всякий случай:
   ```bash
   mv data/kvalificator.db data/kvalificator.db.broken; rm -f data/kvalificator.db-wal data/kvalificator.db-shm
   ```
3. Вернуть базу из нужной копии и докопировать файлы из зеркала (существующие не перезаписываются):
   ```bash
   cp data/backups/kvalificator-2026-10-14-03-17.db data/kvalificator.db
   cp -rn data/backups/data/files data/backups/data/media data/backups/data/documents data/ 2>/dev/null
   chown -R 1000:1000 data
   ```
4. Запустить и проверить:
   ```bash
   docker compose start app && docker compose exec -T app wget -qO- http://127.0.0.1:3000/health
   ```

**На новый сервер:**

1. Установить проект (`deploy/install.sh`).
2. Перенести папку `data/backups` и файл `.env`.
3. Выполнить шаги 3–4.

Если копия старше текущей версии программы, база обновится сама при запуске (миграции).
